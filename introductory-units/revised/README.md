# Revised Introductory Units

This folder contains revised versions of the introductory units in the parent folder. Each file is narrowed to one clear objective and written to improve scope, flow, and scanability.

Use these versions as a comparison set against the originals in `../`.

## Seven-part rubric

Use this single rubric to review every unit.

| Criterion | What it checks |
| --- | --- |
| Focus and scope | The unit stays on one idea and fits comfortably in about 5 minutes. |
| Logical progression and coherence | The sections build on each other in a clear sequence, and the ideas feel connected from start to finish. |
| Cognitive load and clarity | The explanation is easy to scan, concise, and simple to absorb in one pass. |
| Clarity of learning objective | The unit has one clear outcome and uses an action verb. |
| Instructional substance | The unit teaches a real mechanism, workflow, or example instead of reading like product marketing or a feature list. |
| Actionability and learner progression | The unit helps the learner do something useful or take the next step. |
| Relevance to a real-world scenario | The unit connects the concept to a meaningful use case or job task. |

Each criterion uses a 1-5 scale. The total score is out of 35.
