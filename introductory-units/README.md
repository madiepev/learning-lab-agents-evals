# Introductory Units

Use this folder for units that introduce a product or feature. These units should give learners the first clear explanation of what the product or feature is, why it matters, and what they can do with it.

Suggested contents:
- One unit per file.
- A brief, learner-focused introduction.
- Core concepts, key benefits, and the first practical steps.
- Any supporting assets or notes that help explain the feature.

Keep the content focused on orientation and first-use understanding. When a topic becomes more detailed or scenario-driven, place it in a different unit folder.

## Rubric at a glance

Use this 5-point rubric to review each unit quickly. A score of 1 means the unit is a poor fit for a short Learn step. A score of 5 means it is tight, clear, and ready to publish with little or no trimming.

The last criterion now puts section flow front and center, so the review checks whether each idea naturally leads to the next one.

| Criterion | What a strong score looks like |
| --- | --- |
| Clarity of learning objective | The unit has one clear outcome and uses an action verb, such as describe, configure, or identify. |
| Focus and scope | The unit stays on one idea and fits comfortably in about 5 minutes. |
| Actionability and learner progression | The unit helps the learner do something useful or take the next step. |
| Relevance to a real-world scenario | The unit connects the concept to a meaningful use case or job task. |
| Logical progression and coherence | The sections build on each other in a clear sequence, and the ideas feel connected from start to finish. |

## Score guide

| Total score | Meaning |
| --- | --- |
| 21–25 | High-quality unit, ready to publish. |
| 16–20 | Good unit, but it may need minor refinement. |
| 11–15 | Needs rework for scope or clarity. |
| 10 or below | Fundamentally misaligned with Learn principles. |

## Notes

- The scores are a practical review, not a formal editorial verdict.
