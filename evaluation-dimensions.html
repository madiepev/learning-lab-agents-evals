Learning Lab Agents — Evals

Evaluation Dimensions

Four dimensions used to assess the quality of agent-generated learning content. The first two dimensions are active; dimensions three and four are planned for a later phase.

🎓

Instructional Design

Dimension 1

Evaluates whether the content follows sound learning principles: appropriate level, logical idea progression, and genuine helpfulness for the learner. Each metric is rated on a 1–3 scale.

Metrics — rated 1 (low) to 3 (high)

Appropriate level for learner
1 — Too basic or too advanced
2 — Mostly on-level
3 — Perfectly pitched
Logical progression of ideas
1 — Disjointed or jumps around
2 — Mostly logical flow
3 — Clear, coherent structure
Helpfulness for learning
1 — Unhelpful or confusing
2 — Somewhat helpful
3 — Clearly aids understanding

Concrete examples for each score level (1–3) will be added per metric. These will be validated with instructional design experts to ensure consistent scoring across evaluators.

🔬

Technical Accuracy

Dimension 2

Checks the response against a curated list of known errors — incorrect product names, deprecated terms, and commonly confused references. Each item is a binary pass/fail.

Metric — binary per known error

👍
No known errors
Response uses correct terms and references
👎
Known error present
e.g. "Azure AI Foundry" instead of "Microsoft Foundry"

Examples from the error list

  • "Microsoft Foundry", not "Azure AI Foundry"
  • More errors will be added to the list as they are identified

Content developers can submit new errors to the list by opening a GitHub issue in this repository.
